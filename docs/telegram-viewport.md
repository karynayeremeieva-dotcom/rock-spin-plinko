# Разрешение и экран игры в Telegram Mini App

Источник по API: https://core.telegram.org/bots/webapps (Bot API 8.0, ноябрь 2024, и новее).

## Главное

У Mini App нет фиксированного разрешения. Это веб-страница, которая занимает окно Telegram, а размер окна зависит от устройства и режима. Поэтому игру делаем **резиновой по высоте** под фиксированную ширину. Холст и арт рисуем под базовый размер с запасом.

## Режимы показа

| Режим | Что видит игрок | Как включить |
|---|---|---|
| **Compact** | половина экрана, игру не видно целиком | ссылка `?startapp&mode=compact` или настройка в BotFather |
| **Fullsize** (по умолчанию) | почти весь экран, сверху шапка Telegram с «Закрыть» и «⋯» | `expand()` |
| **Fullscreen** (Bot API 8.0+) | весь экран, шапка прозрачная, кнопки Telegram висят поверх игры | `requestFullscreen()` |

Для игры берём **fullscreen**: максимум места и эффект «настоящей игры». Если устройство не поддерживает режим (событие `fullscreenFailed` с ошибкой `UNSUPPORTED`), откатываемся на fullsize через `expand()`.

## Базовые размеры для дизайна

| | Значение |
|---|---|
| **Макет** | 390 × 844 (iPhone 14/15) — основной |
| **Минимум, на котором всё должно влезать** | 360 × 640 (маленькие Android, iPhone SE: 375 × 667) |
| **Максимум ширины** | 430 (Pro Max). Шире не растягиваем: центрируем колонку до 430 и заливаем края фоном |
| **Ориентация** | только портрет, `lockOrientation()` |
| **Арт** | рисуем в @3x (1170 × 2532 для фона), отдаём сжатый WebP в @2x |

Desktop и Web Telegram открывают Mini App в узком окне. В документации размер не указан, поэтому та же колонка до 430 по ширине на десктопе тоже подходит.

## Безопасные зоны (обязательно в fullscreen)

Две пары отступов, Telegram отдаёт их как CSS-переменные:

- `--tg-safe-area-inset-top/bottom/left/right` — вырез, «чёлка», полоска «домой» у телефона;
- `--tg-content-safe-area-inset-top/...` — кнопки самого Telegram («Закрыть», «⋯»), которые в fullscreen висят поверх игры.

Сверху отступ = сумма обеих зон. Фон рисуется под ними до самого края, а кнопки, баланс и текст — ниже. События `safeAreaChanged` и `contentSafeAreaChanged` приходят, например, при повороте.

## Высота экрана

- `--tg-viewport-stable-height` — по ней прижимаем нижнюю панель (кнопка «Ставка/Крутить»). Она не прыгает во время жестов и анимаций.
- `--tg-viewport-height` — текущая высота, меняется на лету. Для привязки к низу её не используем: так рекомендует сама документация.
- Событие `viewportChanged` с полем `isStateStable`.

## Свайпы

`disableVerticalSwipes()` (Bot API 7.7+) — иначе свайп вниз в игре (например, дёрнуть рычаг или крутить колесо) свернёт приложение. Telegram рекомендует отключать свайпы только при конфликте жестов. В игре он есть.

## Как раскладываем экран игры (сверху вниз)

1. Безопасная зона: вырез + кнопки Telegram (~90–100 px в fullscreen). Тут только фон.
2. HUD: баланс, фриспины, кнопка меню (~56 px).
3. Игровое поле: тянется по высоте. На 640 px сжимается, на 932 px получает воздух.
4. Панель управления: ставка, «Крутить», турбо, автоигра (~150 px), прижата к `viewport-stable-height`.
5. Нижняя безопасная зона (полоска «домой», ~34 px).

## Что покажет знание платформы в тестовом

- fullscreen с откатом на expand;
- обе безопасные зоны;
- фиксированный портрет и отключённые вертикальные свайпы;
- `setHeaderColor` и цвет фона под нашу палитру;
- `HapticFeedback` на ключевых моментах;
- `BackButton` для выхода из правил и истории;
- `enableClosingConfirmation()` во время раунда, чтобы игрок случайно не закрыл приложение посреди спина;
- проверка на 360 × 640, 390 × 844, 430 × 932 и в Telegram Desktop.
