# Rock Spin · Plinko

Plinko for a Telegram Mini App in a rock-club / concert-stage style.
Frontend only: results come from a replaceable fake server module, money is demo.

**Status:** work in progress. A full README (decisions, structure, measurements,
what is missing and why) comes with the final version.

## Run

```bash
npm ci
npm run dev        # http://localhost:5173
npm run check      # types, lint, formatting, multiplier tables, unit tests
npm run build      # production build into dist/
```

Node 20.19+.

## What is in place

- React 18 + strict TypeScript + Vite, board drawn with Canvas 2D (no per-ball DOM nodes)
- `play({ bet, rows, risk })` in `src/api/plinko.ts`: outcome decided with
  `crypto.getRandomValues` before the animation; the ball always lands in the returned bin
- money as integer hundredths of RC; game logic in `src/core/` with no React or Canvas
- all 27 multiplier tables (8–16 rows × Low/Medium/High) in `src/config/multipliers.json`,
  RTP 98.9–99.1 %; rows 9–11 and 13–15 generated by `scripts/generate-multipliers.mjs`
- manual and auto mode with every stop condition, up to 50 balls at once
- history, rules, RU/EN, synthesised sound, big-win animation, localStorage save,
  Telegram integration (ready, expand/fullscreen, haptics, Back button)
